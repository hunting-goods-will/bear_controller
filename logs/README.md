# logs/

Raw run data (the `.csv.gz` files under `human_live_csvs/`, `human_monitor_csvs/`,
`model_validation_csvs/`, `velocity_profile_csvs/`, `spring_characterization/`)
does not live on `main` — it lives on the orphan branch `raw-data`, which
mirrors this directory's paths exactly. Retrieve any file with:

```
git show raw-data:logs/<path> | gunzip > <path minus .gz>
```

e.g. `git show raw-data:logs/human_live_csvs/human_live_20260821_002111.csv.gz | gunzip > run.csv`

`raw-data`'s own `logs/README.md` has the full file index, including a
"Missing data" section on the model-validation gap and an "Update" note on
an anomalous file (see below).

## `summaries/`

One text file per raw `.csv.gz`, generated by running the appropriate
offline analyzer against the decompressed CSV. Each summary's header states
its source file, the exact `git show` command to retrieve that source from
`raw-data`, the analyzer script used, and the commit hash of that script at
generation time (2026-09-17) -- so a summary can always be reproduced or
checked against a newer analyzer version. Mapping:

| Source category | Analyzer(s) |
|---|---|
| `human_live_csvs/*.csv.gz` | `analyze_human_run.py` + `analyze_assist_run.py` |
| `human_monitor_csvs/*.csv.gz` | `analyze_assist_run.py` |
| `model_validation_csvs/*.csv.gz` | `extract_spring.py` (includes its validation-error table) |
| `velocity_profile_csvs/*.csv.gz` | `Analyse_velocity_profile.py` |
| `spring_characterization/bidirectional_sweep_*.csv.gz` | `analyze_bidirectional_sweep.py` |
| `spring_characterization/position_sweep_FINAL_*.csv.gz` | none -- single-direction sweep, no schema-compatible analyzer exists (see that summary file for why) |

## Removed anomalous file

`model_validation_csvs/model_validation_20260820_234335.csv.gz` was removed
from `main` (not summarized) after `extract_spring.py`'s new validation-error
table showed it's a sign-mismatch anomaly, not a bare-rig validation run --
see `raw-data`'s `logs/README.md` for the full analysis. It remains on
`raw-data` for future diagnosis.

## Not summarized (unchanged, still on `main`)

`cyclictest/` (idle/loaded stock-kernel latency baselines) and
`Encoder_values.txt` are small, already-readable text files that are NOT
being removed from `main` -- they stay at their current paths unchanged, so
no separate summary was generated for them.
